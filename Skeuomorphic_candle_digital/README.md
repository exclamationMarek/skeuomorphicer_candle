# Digital Skeuomorphicer Candle
For when you just have to put code into everything

# UNTESTED!
As of releasing this repo, this PCB design is NOT TESTED. It might be all wrong.

# Part list
* CH32V003J4M6 microcontroller in SOP-8 package
* 100k NTC in 0603
* SI2302 NMOS (or similar)
* 1uF capacitor in 0603 for the MCU
* 3V miniature tungsten bulb, or 2x 2835 LEDs
* Some 0603 resistors
* Optionally some 0603 LEDs
* 3xAA or 3xAAA battery holder or 1x LiPo battery
